# CodeAlpha Task 2 - Unemployment Analysis

Part of the CodeAlpha Data Science Internship (October Batch).

## Goal
Clean, explore, and visualize unemployment data in India, and study how COVID-19 affected unemployment rates.

## Steps
1. Loaded the unemployment dataset and checked its structure
2. Cleaned column names and converted dates
3. Plotted the unemployment rate over time
4. Analysed the COVID-19 period (March to June 2020)
5. Found the highest unemployment rate
6. Compared average unemployment across regions
7. Created a correlation heatmap

## Key Finding
Unemployment rose sharply during the COVID-19 lockdown months of 2020.

## Tools Used
Python, Pandas, Matplotlib, Seaborn

## How to Run
Open `unemployment_analysis.ipynb` in Google Colab, upload `Unemployment_Rate_upto_11_2020.csv` when asked, and run all cells from top to bottom.
